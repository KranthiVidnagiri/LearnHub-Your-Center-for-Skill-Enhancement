
 🎓 LearnHub Center

**LearnHub Center** is a full-stack learning platform designed to help students explore **courses, practice coding problems, and track their learning progress**. Inspired by platforms like GeeksforGeeks, it was developed as a **live project during my SmartInternz Internship** to gain **real-world full-stack development experience**.

---

## 🚀 Features

- ✅ **User Authentication** – Secure login & signup using JWT
- 📚 **Course Management** – Browse, enroll, and access structured learning paths
- 🎥 **Learning Resources** – Video tutorials, articles, and notes in each course
- 📊 **Student Dashboard** – Personalized space to view enrolled courses & progress
- 🗂️ **Teacher Panel** – Manage users, courses, and content efficiently
- 📱 **Responsive UI** – Seamless experience across desktop, tablet, and mobile

---

## 🛠️ Tech Stack

- **Frontend:** React + Tailwind CSS
- **Backend:** Node.js + Express.js
- **Database:** MongoDB
- **Authentication:** JWT (JSON Web Token) + Bcrypt
